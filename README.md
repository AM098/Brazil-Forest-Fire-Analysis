## Brazil Forest Fire Analysis 

Exploratory data analysis of forest fires reported in Brazil, using Python, Pandas, and Matplotlib/Seaborn. The project covers data inspection, cleaning, and time-based and state-wise analysis of fire counts.

  - What this project covers
  - Data inspection: viewing the first and last rows, checking shape, data types, memory usage, and summary statistics
  - Data cleaning: finding and dropping duplicates, checking for null values, and translating month names to English
  - Overall insights: total fires registered, and the month, year, and state with the most fires
  - Amazonas deep dive: total fires, plus year-wise and day-wise breakdowns
  - Visualization: month-wise fires for 2015
  - State-wise analysis: average fires per state (highest to lowest) and the states with fires reported in December

 
## Tech stack
   - Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
